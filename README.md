# स्वराज्यवेध | SWARAJYAVEDH

A research-first Marathi digital historical experience dedicated to understanding Chhatrapati Shivaji Maharaj and the era of Swarajya.

## Status

Initial mobile-first UI foundation. Research archive, maps, chronology, and literary manuscript are **planned**, not yet implemented. Historical claims will require source-level verification before publication.

## Preview

Open `index.html` in a browser or serve this repository with any static HTTP server.

## Structure

- `index.html`: accessible Marathi landing page and navigation
- `styles.css`: responsive visual design system
- `script.js`: mobile navigation behavior

## Editorial commitments

1. Research before narrative publication.
2. Distinguish verified records, interpretations, disputed traditions, and literary reconstruction.
3. Do not invent archival evidence.
4. Preserve independent original prose and attribution.

The previous ShivVedh repository is not modified by this project.
